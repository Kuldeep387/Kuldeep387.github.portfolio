# Kuldeep Ahirwar Portfolio

Open `index.html` in a browser, or use VS Code + Live Server.

Included:
- Real profile photo
- Resume download
- GitHub + LinkedIn
- Email and phone contact
- Animated skill bars
- Dark/light mode
- Responsive mobile navigation
- Projects and internship experience from the uploaded resume

To add individual GitHub repositories, replace the GitHub profile URLs in `index.html`.
To add certificates, put the certificate files inside `assets/` and add cards in the Certificates section.
